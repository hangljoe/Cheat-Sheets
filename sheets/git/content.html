Daily loop

  1. git pull latest changes
  2. git switch -c feat/x new branch
  3. Edit, then git add -p hunk by hunk
  4. git commit -m "…" small & focused
  5. git push -u origin feat/x → open PR

Merge vs rebase

merge

  • Keeps true history
  • Adds merge commit
  • Safe on shared branches

rebase

  • Linear, clean log
  • Rewrites SHAs
  • Only on your branches

Golden rules

Never force-push a shared branch. If you must: --force-with-lease.

Commit small: one idea per commit, message says why.

Lost work? git reflog remembers everything.
